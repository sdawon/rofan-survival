## 0. 핵심 원칙 한 줄

**세계는 로판 클리셰대로 굴러가려 하고, 클리셰를 비트는 건 플레이어인 '나'뿐이다.**

이걸 게임 규칙으로 옮기면 세 가지가 됩니다.

1. **개연성 (확정, 2026-10-01 사용자):** 개연성 = '나'가 하스제라 28년 겨울까지 튜토리얼에서 겪은 것들 + 로판 클리셰. '나'가 손대지 않으면 모든 사건은 이 개연성대로 흘러간다. 인물설정의 "정해진 흐름" 칸이 바로 이 개연성의 결과.
2. **보정 (후보):** 개연성의 한 조각을 깨면 세계가 빈자리를 메우려고 다른 방식으로 같은 결과를 밀어붙인다. (사용자 메모 "개연성을 비틀면 다른 사람이 독살을 시도할 수도 있다"를 일반 규칙으로 확장)
   - 보정의 재료도 개연성이다. 세계는 '나'가 튜토리얼에서 본 사건이나, 아직 안 쓴 다른 클리셰를 꺼내 대체 사건을 만든다. 그래서 대체 사건은 플레이어가 "어디서 본 것 같은" 모양이 된다.
   - '나'의 미래 지식이 정확한 건 개연성이 그대로일 때뿐이다. 비튼 만큼 튜토리얼 기억과 실제가 어긋난다.
3. **상태창은 세계의 눈이다:** 상태창은 "세계가 인지한 것", 즉 클리셰의 시선으로 인물을 보여 준다. 그래서 틀릴 수 있다. (바이블 확정 "상태창 정보는 틀릴 수 있다"와 맞물림. 상태창이 틀리는 **이유**를 이걸로 설명하자는 제안)

### 바이블과의 관계 체크
- 충돌하는 부분은 없습니다.
- 3번(상태창 = 클리셰의 시선)은 바이블에 없는 **해석 추가**입니다. 세계의 정체(미정 사항)에 대한 힌트가 될 수 있어서 정해 두면 좋습니다.
- 인물설정 파일은 '왕녀', 바이블은 '외국 공주'로 부릅니다. 이 문서는 **왕녀**로 통일했습니다.

## 1. 비틀기 시스템 아이디어 (후보)

스토리 쪽에서 쓰기 좋은 장치만 골랐습니다. 숫자·로직은 스탯 스레드에서 정하면 됩니다.

| 장치 | 내용 | 왜 좋은가 |
|---|---|---|
| **클리셰 플래그** | 각 사건에 "클리셰대로 진행 / 비틀림" 상태를 붙인다. 예: `로잘린_기사단장_집착 = 클리셰` | 엔딩 조건을 "비튼 클리셰 몇 개, 어떤 것"으로 짤 수 있음 |
| **세계의 보정** | 비튼 클리셰가 있으면 세계가 대체 사건을 만든다. 예: 황후의 독살을 막으면 다른 인물이 독을 든다 | 한 번 막고 끝이 아니라 "진짜 원인"을 찾아야 하는 동기가 생김 |
| **클리셰 도감** | 처음 발견한 클리셰와 처음 비튼 클리셰를 수집. "악녀의 집착(발견)", "악녀의 집착(비틂)" | 다회차 수집 재미와 직결 (바이블: 핵심 재미 = 엔딩 수집) |
| **상태창 오보** | 상태창 문구가 클리셰 그대로 뜨고, 진실을 알면 문구가 갱신된다. 예: "로잘린: 황실기사단장에게 집착" → "로잘린: 황실기사단장을 무서워함" | 바이블 확정 "진실을 알수록 정보가 갱신된다"를 그대로 활용 |
| **너무 많이 비틀면** | 비튼 수가 많아지면 세계가 '나'를 이물질로 인식하기 시작 (특정 인물이 눈치챔, 이상 현상) | 트루엔딩·세계의 정체로 이어지는 떡밥 |

## 2. 공통 클리셰 목록 (세계 전체)

각 줄: **클리셰** / 세계가 밀어붙이는 방식 / 비트는 방법 아이디어

### 2-1. 황실·정치
- **황후는 질투로 미쳐 있다** / 황비 소생을 노린다 / 증거를 모아 고발, 황후의 아군(공작가)을 끊기, 황후의 동기 자체를 해소하는 루트(질투의 근원을 파고드는 이벤트)
- **황태자 vs 2황자 후계 구도** / 귀족가가 양쪽으로 줄을 선다 / 제3의 선택지: '나'가 직접 황제가 되는 루트(바이블의 황제 엔딩), 둘의 화해, 후계 구도 밖의 인물 밀기
- **비천한 출신의 황비** / 세상이 황비와 그 자식을 깔본다 / 출신의 진실(무희, 남쪽나라, 타 종족 혼혈 느낌) 발굴 이벤트
- **황제는 무관심하거나 무능하다** / 황궁의 일을 방치한다 (후보, 아직 설정 없음) / 황제를 움직이는 이벤트

### 2-2. 가문·가족
- **애지중지 막내딸** / 겉보기엔 사랑, 속은 정치 도구 / "대화가 필요해" 이벤트, 가족 오해 해소
- **딱딱하지만 속정 깊은 오빠** (로판 단골) / 세계는 공작가 오빠를 이 클리셰로 포장 / 실제로는 이중적인 인물이라는 걸 폭로. **클리셰가 거짓말인 경우**의 대표 사례로 쓰기 좋음
- **눈에 띄지 않는 언니** / 공작가 언니가 배경으로 남는다 / 언니에게 스포트라이트를 주는 이벤트 (황후가 아스트라를 노린 이유와 연결될 수 있음)
- **가난한/몰락한 백작가** (후보) / 백작영애 설정 미정이라 열어 둠

### 2-3. 사교계·성장
- **데뷔탕트에서 모두의 시선을 받는다** (18살 봄) / 세계의 흐름상 아스트라가 꽃이 된다 / 다른 빙의 대상이 무대를 뺏기, 데뷔탕트를 거부하기, 데뷔탕트 대신 다른 일정
- **찻잔 속 음모 (다과회, 드레스에 와인 쏟기)** / 악녀가 일으키는 사건으로 처리된다 / 진짜 범인 찾기, 역으로 증거 확보
- **아카데미/가정교사 수업** / 여주는 천재성을 드러낸다 / 육성 스탯과 직접 연결되는 지점
- **신분을 숨긴 봉사·외출** / 거기서 운명의 남자를 만난다 / 만나지 않기, 다른 사람이 만나게 하기

### 2-4. 연애
- **남자 4인에게 사랑받는 여주** (2026-10-02 사용자 확정: 황태자, 황실기사단장, 마탑주, 외국 왕) / 세계는 아스트라 쪽으로 호감을 몰아준다 / 우정 엔딩(바이블 확정), 호감을 다른 인물에게 돌리기
- **연애는 데뷔탕트 이후** (사용자 확정: 18살 봄 데뷔탕트 전에는 썸까지만) / 세계는 어린 시절의 썸을 운명의 복선으로 쓴다 / 썸을 끊거나 다른 사람에게 돌리면 데뷔탕트 이후 판도가 바뀜
- **진실을 보는 성직자** (사용자 확정: 대신관은 연애 루트에서 제외, 진실을 보는 존재) / 세계는 대신관을 '나'의 정체를 꿰뚫는 인물로 둔다 / 대신관에게 정체를 들키는 이벤트, 상태창이 틀린 정보를 대신관이 바로잡아 주는 이벤트 (후보)
- **이국의 왕과 외교관** (사용자 제안: 왕녀와 함께 온 왕이나 외교관) / 외국 왕은 여주에게 반해 제국에 머문다 / 왕녀 루트와 엮기 (외국 왕과 왕녀의 관계는 남자 인물 스레드에서 정할 것)
- **악녀는 남주에게 집착한다** / 로잘린이 기사단장을 쫓아다니는 것으로 소문 / 진실(실은 무섭다고 생각함)을 드러내기
- **소꿉친구 = 운명** / 아스트라와 기사단장을 엮는 소문 / 둘 다 원하지 않는다는 걸 증명
- **계약 연애·계약 결혼** (후보) / 아직 인물 없음, 남자 인물 스레드에서 쓸 수 있음
- **회귀자를 알아보는 남자** / 바이블 피드백에서 나온 "남주가 회귀를 눈치챈다" / 루트마다 다른 남자가 다른 이유로 눈치채도록

### 2-5. 장르 자체 (빙의·회귀)
- **회귀자는 미래를 알아 무쌍한다** / '나'도 튜토리얼에서 본 미래를 안다 / 비틀수록 미래 지식이 틀려진다(세계의 보정). 미래 지식은 1회차에서만 정확
- **빙의자는 시스템의 도움을 받는다** / 상태창이 뜬다 / 상태창이 틀린다(바이블 확정)
- **빙의된 몸의 원래 주인은 사라진다** / 아무도 신경 안 씀 / 원래 영혼의 행방을 트루엔딩 떡밥으로 (피드백 ⑤)
- **엑스트라는 이름도 얼굴도 없다** / 튜토리얼의 '나' / 다섯 번째 빙의 대상으로 '나'에게 이름과 얼굴을 찾아 주는 루트

## 3. 빙의 대상별 클리셰와 비틀기

형식: **세계가 정한 흐름** → **따라가는 클리셰** → **비틀기 선택지·이벤트 아이디어** → **진엔딩과의 연결**

### 3-1. 로잘린 (황녀, 악녀) — 1회차 해금

**세계가 정한 흐름:** 아스트라 독살 음모에 빠져 20살에 투옥, 21살쯤 처형.

**따라가는 클리셰**
1. 악녀 황녀는 미모와 사치로 무장한다
2. 악녀는 남주(기사단장)에게 집착한다
3. 악녀는 여주(아스트라)를 질투해 괴롭힌다
4. 악녀는 사용인에게 못되게 군다
5. 악녀는 누명을 쓰고 처형된다 (악녀 처형 엔딩)
6. 비천한 출신의 어머니

**비틀기 아이디어**
- **기사단장 집착 소문 끄기:** 기사단장과 거리를 두는 선택지를 반복하면 소문 수치가 떨어짐. 대신 "그럼 누굴 좋아하냐"는 시선이 소백작에게 향하는 위험 이벤트
- **소백작과의 수업:** 도서관 가정교사 수업을 스케줄로 넣을 수 있음. 지식 계열 스탯과 연결. 연구자로서의 로잘린이 드러나는 이벤트. 소백작은 로잘린과 1살 차이 나는 천재(사용자 확정). 데뷔탕트 전에는 썸까지만
- **사용인 관계 회복:** 못되게 굴던 이유(살해 위협 때문의 예민함)를 사용인이 알게 되는 이벤트. 사용인 중 황후 첩자를 찾는 미니 추리
- **아스트라와 직접 대화:** 질투가 아니라 공작가 오빠 때문이라는 걸 아스트라가 알게 되는 이벤트. 두 사람 연대 루트로 갈 수 있음
- **공작가 오빠 대응:** 추행 시도 이벤트를 회피/증거화/역공. 이걸 폭로하면 아스트라 루트에도 영향 (교차 회차 연결)
- **황비 출신 추적:** 남쪽나라 상인, 무희 시절 지인, 유품 아이템. 진엔딩 조건과 직결
- **독살 누명 대비:** 20살 투옥 전에 알리바이·증인·해독제 확보. 막으면 세계의 보정으로 다른 누명이 생기는 구조

**미래 지식 활용 포인트:** '나'는 튜토리얼에서 재무담당으로 로잘린을 봤다. 그때 본 장부·지출 기록이 단서가 될 수 있음 (예: 황후 쪽 수상한 지출)

**진엔딩 연결:** 소백작과 결실 + 황비 출신 공개 + 무덤을 남쪽나라에 안치 + 제국을 떠나 연구하며 산다. 즉 **"악녀는 처형되거나 개과천선해 남주와 이어진다"는 클리셰 둘 다를 거부하고 떠나는 엔딩.** 클리셰 비틀기의 모범 사례.

### 3-2. 아스트라 (공녀, 이 세계의 주인공) — 다회차 해금

**세계가 정한 흐름:** 남자 4인에게 사랑받고, 악녀에게 괴롭힘당하지만 이겨내고, 황태자와 결혼해 황후가 되어 행복하게 산다.

**따라가는 클리셰**
1. 성녀 같은 여주
2. 역하렘 (황태자, 황실기사단장, 마탑주, 외국 왕)
3. 공작가의 애지중지 막내딸
4. 소꿉친구 남자와의 운명
5. 악녀의 괴롭힘을 견디는 여주
6. 황후가 되는 해피엔딩

**비틀기 아이디어**
- **성녀 이미지 깎기:** 일부러 실수하거나 솔직한 감정을 드러내는 선택지. 평판은 떨어지지만 "진짜 아스트라"를 보는 인물이 생김
- **역하렘 정리:** 남자 인물마다 호감 대신 우정/거리 두기를 고를 수 있게. 4인 중 누구도 고르지 않는 루트
- **마탑주:** 신설 인물. 마법 계열 스탯과 연결되는 썸 후보. 데뷔탕트 전에는 썸까지만
- **외국 왕:** 왕녀와 함께 제국에 온 인물이라면 아스트라를 향한 호감이 왕녀 회차에서는 다르게 보일 수 있음 (교차 회차 연결 후보)
- **기사단장과의 오해 풀기:** 둘이 같이 "우린 아니다"를 증명하는 이벤트. 의외의 우정 루트
- **가족과 대화:** 정치 도구였다는 사실을 아스트라가 먼저 알아채고, 진짜 대화를 하는 이벤트 체인 (진엔딩 조건 후보)
- **오빠의 이중성 직면:** 아스트라 시점에서는 "불편한 오빠"였던 사람이 로잘린에게 한 일을 알게 되는 이벤트. 다른 회차(로잘린)에서 얻은 기억이 있으면 선택지가 열림
- **언니 지키기:** 황후가 아스트라를 노린 이유와 언니가 연결된다면, 언니를 지키는 것이 독살을 막는 열쇠가 됨
- **봉사활동 남자:** 신분을 숨긴 봉사에서 황태자를 만나는 건 클리셰지만 진엔딩 경로. 이걸 "클리셰를 알면서도 고르는 선택"으로 보여 주면 재미있음

**핵심 반전 포인트:** 아스트라 루트는 **"클리셰를 따라가도 되는 루트"**. 진엔딩이 결국 황태자와 사랑·명예·권력이다. 차이는 '정해진 흐름'에서는 남이 만든 행복이고, 진엔딩에서는 아스트라가 고르고 쟁취한 행복이라는 점. "같은 결말이라도 과정이 다르다"를 보여 주는 루트로 쓰자는 제안.

**진엔딩 연결:** 봉사활동에서 황태자 → 가족 오해 해소 → 진짜 사랑받는 딸 → 사랑·명예·권력 모두.

### 3-3. 백작영애 (이 세계 주인공의 친구) — 1회차 해금, 설정 미작성

설정이 비어 있어서 **클리셰 후보만** 정리했습니다. 확정된 것은 "아스트라의 친구"와 "소백작의 동생"뿐입니다.

**흔한 '여주 친구' 클리셰 후보**
1. 여주의 연애를 돕는 조력자, 자기 이야기는 없음
2. 여주를 질투해 배신하는 친구 (반전형)
3. 서브 남주와 이어지는 친구
4. 가난하거나 몰락한 가문
5. 정보통·수다쟁이
6. 오빠(소백작)를 여주와 엮으려는 동생

**비틀기 아이디어 후보**
- **조력자 거부:** 아스트라 연애 이벤트에서 빠지고 자기 일정을 고르는 선택. 자기 이야기를 시작하는 순간
- **오빠와 로잘린 사이:** 소백작이 로잘린을 가르치는 걸 가장 먼저 아는 인물이 될 수 있음. 로잘린-소백작 루트의 열쇠이자 방해꾼 둘 다 가능
- **정보통 → 황궁 행정:** 엑스트라 '나'의 행정원 경력과 겹치는 커리어 루트 후보 (황제 엔딩과 연결?)
- **두 친구 사이:** 아스트라와 로잘린을 이어 주는 다리 역할. 우정 엔딩의 중심 후보

**정해야 할 것:** 백작영애 본인의 "정해진 흐름"(개입하지 않으면 어떻게 되는지)이 있어야 비틀기 선택지가 구체화됩니다.

### 3-4. 왕녀 (무역강국, 서브 여주) — 다회차 해금, 설정 미작성

**흔한 '외국 공주' 클리셰 후보**
1. 정략결혼을 위해 제국에 온다
2. 남주를 두고 여주와 경쟁하는 서브 여주
3. 이국적이고 당돌한 성격
4. 볼모(인질)로 와 있다
5. 결국 본국으로 돌아가거나 서브 남주와 이어진다

**비틀기 아이디어 후보**
- **무역 능력:** 무역강국 출신이라는 점을 스탯·경제 이벤트로. 재무담당이었던 '나'의 기억과 시너지
- **정략혼 거부 / 정략혼 역이용:** 결혼 상대를 고르는 쪽이 왕녀가 되는 반전
- **경쟁 대신 동맹:** 아스트라와 남주를 두고 싸우지 않고 사업 파트너가 되는 루트
- **제국과 본국 사이:** 볼모라면 본국에 돌아가는 엔딩, 제국에 남는 엔딩, 두 나라를 잇는 엔딩
- **황제 엔딩 후보:** 외국 왕녀가 제국 정치에 들어가는 건 가장 큰 클리셰 파괴. 다만 혼자 황제가 되는 엔딩이 누구에게 열리는지는 미정

**정해야 할 것:** 나라 이름, 왜 회귀 시점(16살)에 제국에 있는지, 정해진 흐름.

### 3-5. 엑스트라 '나' — 다섯 번째 빙의 대상

**세계가 정한 흐름:** 이름도 얼굴도 없이, 20살 겨울(하스제라 28년)에 황궁 행정원으로 죽는다. (튜토리얼)

**따라가는 클리셰**
1. 엑스트라는 이야기에 영향을 주지 않는다
2. 엑스트라는 주요 사건에 휘말려 죽는다 (튜토리얼 죽음)
3. 빙의자는 결국 주요 인물이 되려 한다

**비틀기 아이디어**
- **엑스트라로 남기:** 주요 인물이 되지 않고 엑스트라 자리에서 모든 걸 바꾸는 루트. "주인공이 아니어도 세계를 바꾼다"
- **이름과 얼굴 찾기:** 튜토리얼에서 남의 외형은 정했는데 내 외형은 없었다. 이 루트에서 비로소 '나'의 외형을 정하는 연출 (피드백에서 칭찬한 "얼굴 없는 나" 연출의 완성)
- **네 인물과의 재회:** 다른 회차에서 빙의했던 네 인물을 '나'로서 만나는 이벤트. 그들이 '나'를 기억하는지가 트루엔딩 조건 후보
- **죽음의 원인 추적:** 튜토리얼에서 왜 죽었는지가 세계의 정체와 연결

**진엔딩/트루엔딩 연결:** 다섯 번째 대상이라 트루엔딩과 가장 가깝습니다. 피드백 ④ 후보 A("네 진엔딩을 봐야 열리는 원래의 나")와 잘 맞습니다.

## 4. 교차 회차 연결 (한 인물에서 비튼 것이 다른 인물에게 미치는 영향)

다회차의 재미를 살리는 연결 고리 후보입니다.

| 회차에서 알아낸 것 | 다른 회차에서 열리는 것 |
|---|---|
| 로잘린 회차: 공작가 오빠의 추행 | 아스트라 회차: 오빠의 이중성을 직면하는 선택지 |
| 로잘린 회차: 소백작과의 관계 | 백작영애 회차: 오빠의 비밀을 아는 선택지 |
| 아스트라 회차: 공작가가 황태자 지지 때문에 비교 구도를 만든 사실 | 로잘린 회차: 공작가를 적대하지 않고 협상하는 선택지 |
| 아스트라 회차: 독살 진범이 황후 | 모든 회차: 황후 관련 단서가 알림으로 뜸 (회귀자의 기억) |
| 어느 회차든: 상태창 오보 발견 | 해당 인물 정보 갱신이 다음 회차에도 유지 |
