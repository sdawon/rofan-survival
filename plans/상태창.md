# 상태창 구성 (초안)

작성: 2026-10-15, 스레드 "상태창 구성". **사용자 미확인 후보.** 바이블·개발명세서에는 아직 반영하지 않음.
참고: 설정 바이블(상태창 관련 확정 사항), plans/스탯-육성.md, 아이템.md, 클리셰-비틀기.md, 엔딩-회차.md

## 0. 바이블에서 이미 확정된 것

- 튜토리얼이 엑스트라의 죽음으로 끝나면 상태창이 뜬다. 상태창이 곧 '빙의 가능' 기믹이다.
- 첫 상태창은 '빙의 가능' 알림과 빙의 가능한 대상(2/5)을 보여 준다.
- 상태창 정보는 틀릴 수 있다. 1회차 배신 이벤트로 플레이어가 이를 알게 된다.

이 스레드에서 사용자와 이미 나온 이야기(바이블 미반영): 인물을 누르면 '내가 아는 것'이 뜨고, 진실을 알수록 갱신된다. 개연성 수치, 호감도 표면/진심 이중 구조(스탯 초안 3.5).

## 1. 기본 원칙 (후보)

1. **정보는 세 층이다 (2026-10-23 사용자 정리).**
   | 층 | 무엇 | 보이는 곳 |
   |---|---|---|
   | '나'의 인지 | '나'(로판세계 토박이 엑스트라)가 알고 있는 것. 처음엔 대부분 세계의 인지와 같고, 회귀와 플레이를 거듭하며 수정된다 | **상태창** |
   | 세계의 인지 | 평판. 진실이 아니다. 평판이 나쁘면 세계가 그 인물의 성격을 왜곡해서 본다 | 신문(가십지 매달=평판, 관보 가끔=정치), 평판 수치 |
   | 진실 | 제작자(서다원, 박이레)가 정해 둔 세상의 설정. 평판과도 '나'의 인지와도 다를 수 있다 | 직접 보이지 않음. '나'의 인지가 진실에 닿으면 상태창이 고쳐짐 |
   - 상태창이 틀릴 수 있는 이유: '나'의 인지가 아직 진실에 닿지 않아서.
   - 항목 출처 표시 (2026-10-23 확정, 개발용 데이터 구분. 플레이어에게 어떻게 보여 줄지는 별도 미정): **세간의 말**(세계의 인지를 그대로 받아들인 것, 틀릴 수 있음) / **겪은 것**('나'가 직접 본 일) / **확인한 것**(회차 중 진실에 닿아 고쳐진 것).
   - 세간의 말이 진실과 다르면 줄 긋고 확인한 것으로 바뀐다.
2. **지난 회차의 기억 = 상태창에 바로 반영 (2026-10-24 사용자 결정).** '나'가 이미 겪은 것이라 따로 알림을 띄우지 않고 상태창('나'의 인지)이 고쳐진다.
3. **갱신은 지우지 않고 긋는다.** 틀린 정보가 밝혀지면 옛 문구에 줄을 긋고 새 문구를 쓴다. 플레이어가 "내가 이렇게 잘못 알고 있었다"를 계속 볼 수 있게. 예: ~~황실기사단장에게 집착~~ → 황실기사단장을 무서워함

## 2. 내 상태창 (지금 빙의 중인 인물)

| 칸 | 내용 | 틀릴 수 있나 | 출처 |
|---|---|---|---|
| 머리 | 빙의 대상 이름·나이·신분, 날짜(하스제라 ○년 계절), 회차 | 아니오 | |
| 빙의 | 빙의 가능 n/5, 대상 목록(누르면 그 인물 상태창) | 아니오 | 바이블 |
| 능력 | 예법·예술·매력·지성·마력·무력·체력·실무 (8종, 숫자) | 숫자는 정확 | 스탯 초안 3.1 |
| 적성 | 능력별 "높음/보통/낮음/없음" | **예** (로잘린 마력 "없음"이 실제 1.3) | 스탯 초안 3.7 |
| 상태 | 스트레스, 자금 | 아니오 | |
| 사회 | 평판 | 숫자는 정확, 이유 설명은 클리셰 시선 | 스탯 초안 3.3 |
| 위화감 | 주변이 "사람이 변했다"고 느끼는 정도 | 아니오 | 스탯 초안 3.2 |
| 개연성 | 세계가 정해진 흐름대로 가려는 힘. 숫자는 숨기고 구간별 문구로 보여 줌 | 아니오 | 스탯 초안 3.6 |
| 가방 | 아이템, 설명은 상태창 설명 | **일부 예** (선물 취향, 해독제/독) | 아이템.md |

- 빙의 대상 칸에서 아직 빙의 못 하는 인물은 실루엣 + 잠금.
- 엑스트라('나' 자신)는 다섯 번째로 열리고, 위화감 칸이 없다(원래 '나'라서).

## 3. 상대방 상태창 (인물 카드)

인물을 누르면 뜬다. 핵심은 **두 칸 나란히**다.

| 칸 | 내용 |
|---|---|
| 머리 | 일러스트, 이름·나이·신분 |
| **내가 아는 것** | 한 칸뿐. 항목마다 세간의 말 / 겪은 것 / 확인한 것 표시. 엑스트라가 소문조차 모르는 인물은 ???로 시작 (사용자 결정) |
| 표면 호감도 | 숫자. '나'에게 보여 주는 태도 |
| 진심 호감도 | 처음 ???, 진실 항목 1개마다 구간(낮음/보통/높음), 전부 알면 숫자 (스탯 초안 3.5) |
| 진실 | 진실 항목 n/m. 잠긴 칸은 자물쇠, 몇 개 남았는지만 보임 |
| 취향 | 선물 취향. 세간의 말이면 틀릴 수 있음 (로잘린: 보석 → 책) |
| 관계 | 다른 인물과의 관계 한 줄씩 (관계도.md) |
| 기록 | 이 인물에게 배신당한 회차가 있으면 경고 표시 (스탯 초안 7.2) |

- 진실 정보는 회차를 넘어 남는다(엔딩-회차.md 5장: 진실은 몸이 아니라 '나'가 아는 것). 남주 호감은 남지 않는다.
- 1회차 배신 이벤트: 표면 80, 진심 ???인 인물을 믿었다가 당한다. 이후 그 카드에 "기록" 경고가 뜬다.

## 4. 더 생각할 부분 (사용자 결정 필요)

1. **개연성을 내 상태창에 보여 줄까?** 숫자 / 문구만("세계가 흐름을 되돌리려 한다") / 숨김.
   기본값: 문구만. 숫자로 보이면 게임이 계산 문제가 되고, 숨기면 비틀기의 대가가 안 보임.
2. ~~**'내가 아는 것' 칸은 언제 생기나?**~~ → **결정: 못 만난 인물은 ???로 시작.** 튜토리얼에서 만난 인물만 처음부터 채워질까, 못 만난 인물(예: 이졸데)은 "???"로 시작할까.
   기본값: 튜토리얼에서 본 만큼만 채움.
3. ~~**위화감과 '어긋남'은 같은 수치인가?**~~ → **결정: 위화감으로 통일.** 스탯 초안은 "위화감", 엔딩 초안은 "어긋남"으로 같은 개념을 부름. 하나로 합치고 이름을 정해야 함.
   기본값: 같은 수치, 이름은 위화감.
4. ~~**상태창은 왜 틀리나?**~~ → **결정(10-23): '나'의 인지가 아직 진실에 닿지 않아서 틀린다.** (1장 1번 세 층)
   (옛 질문) "상태창 = 클리셰의 시선"으로 정할지. 세계의 정체(미정)에 대한 힌트가 되므로 바이블 결정 사항.
5. **신문 장치와의 정합 (2026-10-15 추가).** 사용자가 분기점 스레드에서 정함: 신문은 세계의 시선, 가십지 매달(평판), 관보 가끔(정치), '현 상태' 인지 장치, "진실은 나와 상태창만 안다". 기존 확정 "상태창 정보는 틀릴 수 있다"와 부딪힘.
   **결정(2026-10-23 갱신): 상태창='나'의 인지, 신문=세계의 인지(평판), 진실=제작자 설정.** (1장 1번)

## 5. 개연성 문구 방식 (1번 질문 답)

내부에는 0~100 숫자를 그대로 두고, 화면에는 숫자 대신 구간별 문구 하나만 띄운다. 코드로는 if/else 한 묶음이다.

```
if   개연성 >= 90: 문구 = A   # 세계가 기억 속 그대로 흐름
elif 개연성 >= 70: 문구 = B   # 작은 어긋남
elif 개연성 >= 40: 문구 = C   # 흐름이 바뀌기 시작
else:              문구 = D   # 기억과 다른 길
if 1년 안에 25 이상 떨어짐: 경고 문구 추가  # 반동 예고 (스탯 초안 3.6)
```

- 구간이 바뀌는 순간에만 문구가 바뀌니, 플레이어는 "뭔가 크게 바뀌었다"는 순간을 느낀다.
- 문구 A~D의 최종 문장은 사용자가 쓴다. 목업의 문구는 자리 채우기용 예시.
- 목업: https://claude.ai/artifact/V5jm1gFkyiwKiQBe7ruTS1

## 6. 기억 조각 (2026-10-23 사용자 확정, 상태창과 연결)

- 빙의 대상의 **기억 조각**이 조건을 만족하면 열린다. 조건은 다양하게 둔다(모두 후보): 특정 장소 방문, 특정 인물과 만남, 특정 스탯 달성 등.
- **한계:** 조각에는 그 인물이 본 것만 담긴다. 예: 로잘린의 기억으로도 아스트라 독살의 진범은 모를 수 있다. 그래서 다른 인물로 회차를 돌 이유가 생긴다.
- 조각을 얻으면 그 내용만큼 상태창('나'의 인지)이 고쳐진다. 출처 표시로는 **확인한 것**이 된다.
- 기억 조각 = 빙의 대상의 기억 (2026-10-24 사용자). 플레이어가 그 인물에 몰입하게 하는 장치. 엑스트라도 다섯 번째 빙의 대상이라 엑스트라의 20년 기억도 같은 장치로 보여 줄 수 있다(후보).
- **엑스트라 이름: 세실 (2026-10-24 사용자 확정).**
