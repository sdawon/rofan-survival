# 로판에서 살아남기 (가제)

프린세스 메이커류 로판 육성 게임의 스토리 기획 저장소입니다.

## 정답지

설정이 서로 다르면 아래 두 문서가 기준입니다.

- **설정 바이블** (스토리 설정): https://claude.ai/code/artifact/3913cf02-474b-4171-b488-14165d623089
- **개발명세서** (시스템·기술 명세): https://claude.ai/code/artifact/a431046e-c5e2-4ed3-b38b-2316a7c7bb73

이 저장소의 `plans/` 문서는 초안입니다. 바이블과 다르면 바이블이 우선입니다.

## 폴더

| 폴더 | 내용 |
|---|---|
| `characters/` | 인물 설정 |
| `plans/` | 분야별 기획 초안 (스탯, 아이템, 지역, 관계도, 분기점, 엔딩 등) |
| `feedback/` | 피드백 기록, 설정 점검표 |
| `bible/` | 설정 바이블을 내보낸 사본 (원본은 위 바이블 링크. 사본은 자동으로 맞춰지지 않음) |
| `opinions/` | 의견 모음 안내 |

## 협업 규칙

1. **문서를 고치고 싶을 때**: 새 브랜치를 만들어 수정하고 Pull Request(PR)를 엽니다. `main`에 바로 올리지 않습니다.
2. **의견만 남기고 싶을 때**: 아래 중 편한 곳에 남깁니다.
   - **"의견 모음" PR**의 댓글 (특정 문장에 다는 의견은 PR의 *Files changed* 탭에서 줄 옆 `+`를 눌러 남기면 좋아요)
   - **Issue** (주제 하나에 Issue 하나)
3. 새 댓글은 매시간 확인해 요약하고, 바이블과 부딪치는 부분이 있으면 짚어 둡니다.
4. "원작"이라는 표현은 쓰지 않습니다. 이 세계에는 원작 개념이 없습니다.

## 설정 반영 규칙 (2026-10-24)

1. **확정**은 다원이 직접 "확정"이라고 말한 것만입니다. 후보를 정리하면서 확정으로 바꾸지 않습니다.
2. **"반영해"**를 들으면 먼저 바이블의 결정 로그에 한 줄(날짜, 결정, 영향받는 문서)을 적습니다. 바이블과 부딪치면 고치기 전에 묻습니다.
3. 각 스레드는 **자기 담당 문서만** 고칩니다. 다른 문서에 들어갈 내용은 바이블의 **'하위문서 반영 대기'** 목록에 남깁니다.
4. **"전체 반영해"**를 들으면 대기 목록에 있는 문서만 한 번에 고치고 목록을 비웁니다.
5. **"설정 점검해"**를 들으면 문서끼리 어긋난 곳만 표로 뽑아 보여 줍니다 (예: `feedback/2026-10-24-설정-점검.md`). 표에 있는 것은 임의로 고치지 않습니다.

이 저장소와 Claude 프로젝트 폴더는 자동으로 맞춰지지 않습니다. 문서가 크게 바뀌면 "깃허브에 올려줘"라고 요청해 주세요.
